This is a vibe-coded project, intended to count cards on a 52-card deck, specifically made for roleplaying Wester Gothic V2, the RPG where playing cards and poker hands replace the dice.


The RPG system intends for players to count cards, but it's recommneded to double check with your Dealer about using this software, play fair!

## How to Run This

This is a web-based tool that runs on your computer. You need Python installed to run the backend server.

### 1. Install Python

**Windows:**
1.  Download Python from the official site: [Download Python for Windows](https://www.python.org/downloads/windows/).
2.  Run the installer. **IMPORTANT**: Check the box that says **"Add Python to PATH"** before clicking "Install Now".

**macOS:**
1.  Download Python from the official site: [Download Python for macOS](https://www.python.org/downloads/macos/).
2.  Run the installer and follow the instructions.

### 2. Download the Code
If you haven't already, download this project (click "Code" > "Download ZIP" on GitHub) and extract it to a folder.

### 3. Run the Server

**Windows:**
1.  Open the folder containing the files.
2.  Right-click in an empty space and select **"Open in Terminal"** or hold `Shift` + Right-click and select **"Open PowerShell window here"**.
3.  Type the following command and press Enter:
    ```bash
    py server.py
    ```
    *(If that doesn't work, try `python server.py`)*

**macOS:**
1.  Open **Terminal** (Command + Space, type "Terminal").
2.  Type `cd ` (with a space) and drag the project folder into the terminal window, then press Enter.
3.  Type the following command and press Enter:
    ```bash
    python3 server.py
    ```

### 4. Open the Interface
Once the server is running, open your web browser (Chrome, Firefox, etc.) and go to:
[http://localhost:8000](http://localhost:8000)

---
**Note:** Do not close the terminal/PowerShell window while using the tool. To stop it, press `Ctrl + C` in the window.
